# AI 互動行銷頁實戰 — 目標九宮格

把 AI 行銷頁的所有零件組成一個完整產品:一個讓訪客用 AI 填好
「目標九宮格」(大谷翔平在高中用過的目標達成表方法)、生成專屬桌布、
並自然留下 email 的互動行銷頁 — 從九宮格 UI、AI 補格、AI 桌布生成、
防刷額度、到名單收集後台,全程實作。

本課是 [AI 互動行銷頁實作課](https://yazelin.github.io/ai-marketing-pages-course/)
的進階續作:前課教零件,本課教整合成真產品。

## 方法淵源與商標聲明

「目標九宮格」方法源自原田隆史的原田メソッド(Open Window 64);
大谷翔平高一時於花卷東高校依此方法填寫目標達成表。
「マンダラチャート」は一般社団法人マンダラチャート協会の登録商標です。
本專案為教學用免費工具,與上述組織無從屬關係。
