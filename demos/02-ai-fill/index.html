目標九宮格課程 · DEMO 02(對應第 03 章)

AI 補滿空格

Demo 01 的九宮格,加上一顆「AI 補滿空格」按鈕: 留空的格子交給 LLM,已填的格子一字不動。 AI 補的格子會掛上金色標記,改字後標記消失(它就變成你的了)。

Groq API Key 設定(第一次使用必填)

本 demo 由瀏覽器直連 Groq 的 LLM API。先到 console.groq.com 免費註冊,在「API Keys」建立一把 key(gsk_ 開頭),貼到下面。

Key 只存在你瀏覽器的 localStorage,本頁沒有任何伺服器。 但「前端直連」表示 key 攤在瀏覽器裡 —— 只適合自用練習; 正式版會把 key 收進 Cloudflare Worker,瀏覽器永遠看不到(第 03 章的重點)。
